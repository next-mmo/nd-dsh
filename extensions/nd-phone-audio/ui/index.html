    Troubleshooting & Setup Tips (Wi-Fi, USB Tethering, Firewall, Audio Devices)
    • Wi-Fi Mode: Ensure your Windows PC and Android phone are on the same local Wi-Fi/LAN subnet, then scan the QR code and tap Connect & Play Audio in Android Chrome.
    • USB Tethering Mode (No Wi-Fi needed): Connect Android via a USB data cable, turn on USB tethering in Android Network settings, wait a moment or click Refresh Devices & Network, and select the USB Tethering interface.
    • Windows Firewall: If Android hangs while loading the URL over Wi-Fi, allow ND-DSH (or Electron) on Private networks in Windows Defender Firewall, or use USB tethering.
    • Silent audio or missing playback device: Verify an active Windows output (such as Speakers (Realtek(R) Audio) or U27N3R (Intel(R) Display Audio)) is enabled and playing audio. On drivers that silence WASAPI loopback when hardware-muted, unmute Windows and use the Mute PC speakers while streaming option instead.
    • VB-CABLE Optional Fallback: If a specific audio driver blocks Windows loopback, install VB-Audio Virtual Cable, set Windows output to CABLE Input, and choose Virtual Audio Device Fallback → CABLE Output.
