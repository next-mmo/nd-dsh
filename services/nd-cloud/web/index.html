EXPLICIT PROJECT OPT-IN

ZIP source manifests

Metadata only

Owner-only import of a selected ZIP. ND Cloud checks file safety, records hashes and paths, and discards the uploaded archive. It never executes code, auto-publishes Wiki pages, or stores raw source. It creates a review-only source inventory draft. Reviewers may inspect manifests; viewers cannot.

PROVENANCE & INDEPENDENT REVIEW

Source Wiki

Drafts are never auto-published

Every ZIP import creates a deterministic inventory draft with SHA-256 provenance. Owners/reviewers can author a page tied to an exact source file. Another authorized human must publish it. Changes to source snapshots mark previous published pages stale.

HUMAN SPECIFICATIONS

Versioned Specs

Independent review · Source conflict detection

Draft an exact-file-linked human requirement. A different human reviewer must approve the revision. If that source file changes, approval is revoked until you revise/rebase and review again. This does not automatically prove runtime behavior.

REVIEW GOVERNANCE

Knowledge Cards

Drafts are visible only to owner/reviewer roles. Publishing requires a different reviewer than the author. Source links are not automatically verified.
